# gragra

`gragra` is a NumPy-first package for Newtonian gravitational perturbation
calculations. The public `v0.1.0rc2` documentation is deliberately narrow: it
describes a point-source smoke path and a canonical SPECFEM3D Cartesian GLL
input path.

Start with [Getting started](getting-started.md). The numerical assumptions and
failure conditions are part of the [Numerical contract](contracts.md). The
[rc2 scope](rc2-scope.md) and [Verification](verification.md) pages state what
this release does and does not claim.
